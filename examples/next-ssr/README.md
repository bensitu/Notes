# Next.js 公共文章示例

完整构建、启动和自动验证见 [SSR 运行说明](../ssr/README.md)。

首页使用 connection() 在请求时生成服务器时间；文章详情使用 await params、服务端只读数据和 notFound；/static 展示可预渲染页面。计数器是客户端组件，初次仍可参与服务器 HTML，浏览器水合后交互。

源码的 server-only 限制导入边界，不负责业务权限。本项目没有登录、数据库或真实用户数据。将来接入这些能力时按 [SSR 缓存与安全](../../SSR部署与缓存安全.md)检查跨请求状态和缓存边界。

已通过生产构建、类型检查及三项生产浏览器测试。依赖精确版本见 package-lock.json。

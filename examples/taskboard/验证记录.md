## 依赖警告的边界

当前 Boot BOM 下 Flyway 对 H2 版本给出“高于已验证版本”的警告；迁移与测试已运行成功，但不据此宣称所有 H2 特性都受支持，也不能替代 MySQL 验证。

FastAPI 的测试客户端依赖提示 HTTPX 兼容入口将弃用；测试通过，警告没有被全局屏蔽。后续应按 Starlette / FastAPI 的兼容说明配套更新测试客户端依赖。

不同平台的终端颜色或缓存硬链接警告不等于业务失败；仍应区分环境提示、弃用通知与真实错误。

## 前端间接依赖安全更新

2026-11-04 核对并处理了 minimatch 和 glob 的资源耗尽漏洞。它们由 @vue/test-utils → js-beautify → editorconfig / glob 带入，不是页面业务直接安装的依赖。

上游当前版本仍声明旧版本范围，因此在 frontend/package.json 使用 npm overrides，把 glob 固定为 14.0.3、minimatch 固定为 11.0.4，并同步提交锁文件。overrides 表示由本项目指定间接依赖版本；这里涉及跨大版本覆盖，需要实际验证，不能只改锁文件中的数字。Node 24 满足这两个版本的运行要求。

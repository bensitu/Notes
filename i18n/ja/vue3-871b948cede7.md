# Vue 3の開発基盤 :id=h-82f546a01a3a

学習目標：単一コンポーネントから、テストとビルドが可能なプロジェクトへ進みます。先にHTML、JavaScript、非同期リクエスト、既存のVue 3ノートを読んでください。

**適用範囲：**&#x30B5;ンプルはNode 24、Vue 3、Vite 8、Router 5、Pinia 4を使用します。完全な正確なバージョンと依存ツリーはpackage.jsonとpackage-lock.jsonを参照してください。検証済みのvue-tscツールチェーンに合わせ、TypeScriptは5.9.3に固定しています。

## プロジェクトの構成要素 :id=h-e651dc0ce582

| ファイル             | 役割                           |
| ---------------- | ---------------------------- |
| src/main.ts      | アプリを作成し、ルーターとPiniaを登録        |
| src/App.vue      | アプリ共通のレイアウト                  |
| src/TaskPage.vue | ページの操作とフィードバック               |
| src/tasks.ts     | タスクの状態、読み込み、変更操作             |
| src/api.ts       | Cookie、CSRF、ステータスコード、リクエスト処理 |
| vite.config.ts   | 開発用プロキシ、ビルドプラグイン、テスト環境       |

[完全なプロジェクト](examples/taskboard/frontend/package.json)にはロックファイルがコミットされています。既存のプロジェクトではnpm ciを実行し、意図的に依存関係を更新するときだけバージョン変更、再インストール、ロックファイルのレビューを行います。

## 最小限の実行手順 :id=h-33a542671c4f

[プロジェクトの説明](examples/taskboard/README.md)に従ってバックエンドを起動し、リポジトリのルートで次を実行します。

```powershell
Set-Location examples/taskboard/frontend
npm ci
npm run dev
```

ターミナルに表示されたローカルのアドレスを開き、adminとバックエンドのAPP_PASSWORDでログインします。タスクを追加するとリストが更新され、完了をクリックすると状態が変わるはずです。

```powershell
npm test
npm run build
```

buildはVueの型チェックと本番ビルドを両方実行します。開発サーバーの起動成功は型チェックの成功を意味しません。

## リアクティビティとコンポーネントの役割 :id=h-5d65b69dddfa

refは追跡が必要な値に使います。スクリプトでは通常.valueでアクセスし、テンプレートでは対象となるトップレベルのrefが自動展開されます。computedは派生値を表し、watchは変化後の副作用を実行するもので、すべての算出プロパティの代わりにはしません。

propsは親から渡され、子はイベントで変更を要求します。propsを直接変更したり、参照だけをコピーして編集したりすると、状態の管理元が混乱します。

コンポーザブルは検索リクエストのキャンセルや読み込み状態など、再利用可能な状態付きの動作をまとめるのに適しています。ページ全体を巨大な1つのuseEverything関数に詰め込まないでください。

<a id="section-4"></a>

## 状態、リクエスト、並行処理 :id=h-cac42e229892

Piniaはコンポーネント間で共有するタスクリストを管理し、入力欄の文字やボタンの処理中状態はページに残します。ブラウザーを再読み込みするとメモリの状態は消えるため、データベースとして扱ってはいけません。

この例は送信中にボタンを無効化し、同じページでの重複操作を防ぎます。サーバーでは引き続きバージョンフィールドで古いデータによる上書きを防ぎます。409の場合は再読み込みしてユーザーに確認し、黙って無限に再試行してはいけません。

TypeScriptの型は外部のJSONを検証しません。この例は応答をunknownとして扱い、タスクのフィールドを1つずつ確認します。解析に失敗したら古いリストを保持してエラーを表示し、「成功した空配列」に変換しないでください。

## 開発と本番の設定 :id=h-f36d7829f4bf

Viteの/apiプロキシは開発専用です。本番イメージではNginxがページを提供し、APIを転送します。VITE_で公開する環境変数はブラウザーのコードに含まれるため、データベースのパスワードや秘密鍵を入れてはいけません。

ルーター、Pinia、UIライブラリは現在のVueのメジャーバージョンに合わせます。更新時は依存ツリー、型チェック、テスト、ビルドをまとめて検証します。すべてのツールの最新タグを自動的に組み合わせても、互換性のある構成にはなりません。

## 検証と開発の早見表 :id=h-e112a2a66c9c

| 現象                       | 確認の方向                                  |
| ------------------------ | -------------------------------------- |
| ブラウザーのリクエストが404になる       | リクエストが/apiを使い、対応するプロキシがあるか確認           |
| 401                      | ログイン済みか、セッションCookieが保存されているか確認         |
| ログイン後にPOSTが403になる        | ログイン後のCSRFトークンを再取得したか確認                |
| 子パスの再読み込みで404になる         | サーバーにSPAエントリーポイントへのフォールバックがあるか確認       |
| ビルドでパッケージのエクスポートパスエラーが出る | 関連ツールが現在のTypeScriptメジャーバージョンに対応しているか確認 |

keyには安定したタスクIDを使用します。長いリストで必要になったらページネーションや仮想スクロールを設計します。この例は最新100件のみを表示し、完全なページネーションを実装したとはしていません。

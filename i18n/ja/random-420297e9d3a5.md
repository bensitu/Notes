## Random とは :id=h-641007e74d21

java.util.Random は、アルゴリズムとシードから計算する擬似乱数を生成します。同じシードを使い、同じ順序でメソッドを呼べば、同じ数列になるため、再現性のあるテストに使えます。

```java
import java.util.Random;

public class RandomExample {
    public static void main(String[] args) {
        Random random = new Random(42L);
        System.out.println(random.nextInt(10));
        System.out.println(random.nextDouble());
        System.out.println(random.nextBoolean());
    }
}
```

RandomExample.java として保存し、javac RandomExample.java と java RandomExample を実行します。プログラムを起動し直すたびに同じ数列になります。

## メソッドの早見表 :id=h-bd73409bb033

| メソッド                       | 結果                                          |
| -------------------------- | ------------------------------------------- |
| new Random()               | シードを明示せずに生成器を作る                             |
| new Random(seed)           | 再現可能な実験のためにシードを指定する                         |
| nextInt()                  | int の範囲の整数。負の値も含む                           |
| nextInt(bound)             | \[0, bound)：0 を含み、bound を含まない。bound は正の値が必要 |
| nextLong()                 | long の範囲の整数                                 |
| nextFloat() / nextDouble() | \[0.0, 1.0)：1.0 を含まない                       |
| nextBoolean()              | true または false                              |
| nextGaussian()             | 平均 0、標準偏差 1 の近似的な正規分布                       |

## 整数の範囲を指定する :id=h-8c0427c60ff8

両端を含む \[50, 99] を生成します。

```java
Random random = new Random();
int start = 50;
int end = 99;
int number = random.nextInt(end - start + 1) + start;
```

\[0, 50) を生成して 50 を足すと、50～99 になります。+1 は上限を含めるためのものです。この断片はメソッド内に置き、java.util.Random をインポートしてください。

この式では start <= end であり、end - start + 1 が正の int に収まる必要があります。int 全体の範囲へそのまま適用すると、計算がオーバーフローする場合があります。

## API の選び方 :id=h-362f444747e1

パスワード、認証コード、セッショントークンなど、予測されにくさが必要な場合は java.security.SecureRandom を使います。固定のシードを使ったり、Random の出力を安全なトークンとして扱ったりしないでください。

通常の乱数を高い並行性で使う場合は ThreadLocalRandom を選べます。API を選ぶときは JDK のバージョンを確認してください。新しい範囲指定のオーバーロードは、古い JDK ではそのまま使えません。

参考：[Random API](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/Random.html)、[SecureRandom API](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/security/SecureRandom.html)。

#### 1,2) undefinedとnull :id=h-08aaf23526f2

- 式や関数を実行して戻り値がない場合、undefinedになります。
- 存在しない配列要素やオブジェクトのプロパティにアクセスするとundefinedになります。
- 変数を定義して初期化しない場合、undefinedになります。

例

```js
console.log(1);  	// See note 1 below.
let a = 10;		 	// See note 2 below.
let b = [1,2,3];
console.log(b[10]); // See note 3 below.
let c = {"name":"张三"};
console.log(c.age); // See note 4 below.
let d;
console.log(d);		// See note 5 below.
```

例の説明：

1. 関数に戻り値がないため、結果はundefined
2. 式に戻り値がないため、結果はundefined
3. 未定義の配列要素はundefined
4. 未定義のオブジェクトプロパティはundefined
5. 未初期化の変数はundefined

共通点

- どちらもプロパティやメソッドを持たない
- 両者をまとめてnullishと呼ぶ

相違点

- undefinedはJSが生成する
- nullはプログラマーが指定する

#### 6) boolean :star: :id=h-77b1dbb873d6

- Truthy
- Falsy

JSの条件判定にはboolean以外にも、if文で数値、文字列などを使用できます。

```js
let b = 1;

if(b) { // true
    console.log("进入了");
}
```

条件判定で値をtrueとfalseのどちらとして扱うかという規則があり、trueとして扱う値をtruthy、falseとして扱う値をfalsyに分類します。

次の値はすべてfalsyです。

- `false`
- `Nullish (null, undefined)`
- `0, 0n, NaN`
- ` "" '' `` `：長さ0の文字列

残りの値の大部分はtruthy

falsyと誤解しやすいものの、実際にはtruthyである値：

- `"false", "0"`：falseとゼロの文字列
- `[]`：空配列
- `{}`：空オブジェクト

##### 関数のスコープ :id=h-c42d1091df09

関数は入れ子にでき、JSではよく使われます。入れ子には無名関数やアロー関数を使うことが多くあります。

```js
function a() {
    function b() {
    }
}
```

次の例を見てください。

```js
function c() {
    var z = 30;
}

var x = 10;
function a() {
    var y = 20;
    function b() {
        // See note 1 below.
        console.log(x, y);
    }
    b();
}
a();
```

例の説明：

1. ここに注目

- 関数を境界としてスコープを区切り、すべての関数の外側がグローバルスコープ
- 変数は内側から外側のスコープへ探す
  - 内側で変数が見つかると検索を止め、外側は探さない
  - どのスコープにも変数がない場合はエラー
- スコープは本質的には関数オブジェクトのプロパティで、console.dirで確認してデバッグできる

##### クロージャー :id=h-5b6f7c026a05

```js
var x = 10;
function a() {
    var y = 20;
    function b() {
        console.log(x,y);
    }
    return b;
}
a()();  // See note 1 below.
```

例の説明：

1. 外側でbを実行した

- 関数のスコープは定義時に確定するため、その後どこへ渡されても、そのスコープにあった変数を見つけられます。
- 用語に惑わされないでください。クロージャーとは**関数が自身のスコープの変数にアクセスできること**です。

##### let、varとスコープ :id=h-64bea1806abe

関数が外側のlet変数を参照する場合、通常の外側の{}もスコープの境界になり、最上位のletもscriptスコープを占めます。

```js

    let y = 20;
    function b() {
        console.log(x,y);
    }
    console.dir(b);
}
```

関数が外側のvar変数を参照する場合、通常の外側の{}は境界として扱われません。

```js

    var y = 20;
    function b() {
        console.log(x,y);
    }
    console.dir(b);
}
```

同名のvar宣言は、同じスコープ内の同じ変数として扱われます。

```js
var e = 10;

    var e = 20;
    console.log(e);	// See note 1 below.
}
console.log(e);		// See note 2 below.
```

例の説明：

1. 20を出力
2. 同じ変数なので、やはり20を出力

letなら2つのスコープの2つの変数として扱う

```js
let e = 10;
if(true) {
    let e = 20;
    console.log(e);	// See note 1 below.
}
console.log(e);		// See note 2 below.
```

例の説明：

1. 20を出力
2. 10を出力

内側のeと外側のeを区別する最も簡単な方法は、letに変えるか、関数でスコープを区切ることです。

```js
var e = 10;
if(true) {
    function b() {
        var e = 20;
        console.log(e);
    }
    b();
}
console.log(e);
```

##### 特徴：プロパティの追加と削除 :id=h-f1b651113105

JavaのObjectと比較

- JavaのObjectはクラスをテンプレートに作成され、クラスの範囲を超えられません。プロパティと利用可能なメソッドは決まっています。
- JSのオブジェクトにはテンプレートが不要で、プロパティやメソッドをいつでも追加、削除できます。

```js
let stu = {name:'张三'};
stu.age = 18;					// See note 1 below.
delete stu.age;					// See note 2 below.

stu.study = function() {		// See note 3 below.
    console.log(this.name + "在学习");
}
```

例の説明：

1. プロパティの追加
2. プロパティの削除
3. メソッドの追加

get、setの追加にはObject.definePropertyを使用

```js
let stu = {_name:null};

Object.defineProperty(stu, "name", {
    get(){
        return this._name;
    },
    set(name){
        this._name = name;
    }
});
```

- 引数1：対象オブジェクト
- 引数2：プロパティ名

##### 特徴：this :id=h-3c4260d175f7

まずJavaのthisを理解する

```java
public class TestMethod {

    static class Student {
        private String name;

        public Student(String name) {
            this.name = name;
        }

        public void study(Student this, String subject) {
            System.out.println(this.name + "在学习 " + subject);
        }
    }

    public static void main(String[] args) {
        Student stu = new Student("小明");

        // See note 1 below.
        stu.study("java");
    }
}
```

例の説明：

1. 次のコードは本質的にはstudy(stu, "java")を実行するため、thisはstuです。

- Javaのthisは暗黙の引数
- Javaではthisはメソッドを呼び出すオブジェクトを表します。

JSのthisも暗黙の引数ですが、関数実行時のコンテキストに関係します。

例えば、単独の関数：

```js
function study(subject) {
    console.log(this.name + "在学习 " + subject)
}
```

試してみる

```js
study("js");  // See note 1 below.
```

例の説明：

1. 出力：jsを学習中

この実行ではグローバルオブジェクトwindowがthisになり、windowのnameプロパティは空文字列だからです。

同じ関数をオブジェクトのメソッドにすると：

```js
let stu = {
    name:"小白",
    study
}
```

この場合は現在のオブジェクトがthisになる

```js
stu.study('js'); 	// See note 1 below.
```

例の説明：

1. 出力：Xiaobaiはjsを学習中

thisは動的に変更することもできる

```js
let stu = {name:"小黑"};
study.call(stu, "js");	// See note 1 below.
```

例の説明：

1. 出力：Xiaoheiはjsを学習中

今回はstudy実行時に、callの第1引数stuがthisになります。

例外として、**アロー関数**内のthisは外側のthisとして理解します。

無名関数を使う場合

```js
let stu = {
    name: "小花",
    friends: ["小白","小黑","小明"],
    play() {
        this.friends.forEach(function(e){
            console.log(this.name + "与" + e + "在玩耍");
        });
    }
}
stu.play()
```

- this.nameを含む関数は単独の関数なので、thisはwindowを表します。

出力結果：

```
与小白在玩耍
与小黑在玩耍
与小明在玩耍
```

アロー関数を使う場合

```js
let stu = {
    name: "小花",
    friends: ["小白","小黑","小明"],
    play() {
        this.friends.forEach(e => {
            console.log(this.name + "与" + e + "在玩耍");
        })
    }
}
```

- this.nameを含む関数はアロー関数なので、外側のplay関数のthisを使います。playはstuのメソッドなので、thisはstuを表します。

出力結果：

```
小花与小白在玩耍
小花与小黑在玩耍
小花与小明在玩耍
```

アロー関数を使わない方法

```js
let stu = {
    name: "小花",
    friends: ["小白","小黑","小明"],

        let me = this;

            console.log(me.name + "与" + e + "在玩耍");
        });
    }
}
```

##### 特徴：プロトタイプ継承 :id=h-d0b2fd6c029d


##### 特徴：関数を使うプロトタイプ継承 :id=h-8b6bd0881eda

利便性のため、JSには関数を使ったプロトタイプ継承もあります。

> **関数の役割**
>
> 1. 子オブジェクトを作り、プロパティとメソッドを提供する。機能的にはコンストラクターに相当
>
> 2. 関数の特殊なprototypeプロパティは、その関数が作る子オブジェクトの親オブジェクトです。
>
>    \*\*注意！\*\* 名前は異なりますが、このプロパティの役割は新しいオブジェクトにプロトタイプを提供することです。

```js
function cons(f2) {
    // See note 1 below.
    this.f2 = f2;
    this.m2 = function () {
        console.log("子方法");
    }
}
// See note 2 below.
cons.prototype.f1 = "父属性";
cons.prototype.m1 = function() {
    console.log("父方法");
}
```

例の説明：

1. 子オブジェクト（this）を作り、プロパティとメソッドを提供
2. cons.prototypeが親オブジェクト

newキーワードと組み合わせて子オブジェクトを作成

```js
let son = new cons("子属性")
```

子の`__proto__`は関数の`prototype`プロパティ

##### JSON :id=h-34ed8f5957ff

HTTPリクエスト形式で紹介したJSONは、JSオブジェクトによく似た構文を持ちます。例：

JSONオブジェクトは次のように書けます。

```json
{
    "name":"张三",
    "age":18
}
```

JSオブジェクトは次のように書けます。

```js
const student = {
    name:"张三",
    age:18
};
```

では何が違うのでしょうか。次の点にまとめられます。

1. 本質の違い
   - JSONオブジェクトは本質的には文字列で、クライアントとサーバー間のデータ形式として使われます。プロパティは見かけ上のものです。
   - JSオブジェクトは実際のオブジェクトで、プロパティとメソッドを持てる
2. 構文の細部の違い
   - JSONに使えるのはnull、true|false、数値、文字列（ダブルクォートのみ）、オブジェクト、配列だけです。
   - JSONには上記以外のJSオブジェクトの機能（メソッドなど）は含められません。
   - JSONのプロパティ名はダブルクォートで囲む必要がある

JSON文字列とJSオブジェクトの変換

```js
JSON.parse(json字符串);  // See note 1 below.
JSON.stringify(js对象);  // See note 2 below.
```

例の説明：

1. JSオブジェクトを返す
2. JSON文字列を返す

#### 4) Fetch API :id=h-730520e324a2

Fetch APIはリモートデータを取得し、常にPromiseで非同期の結果を表します。awaitまたはthenで結果を受け取れます。awaitが一時停止するのは現在の非同期関数だけで、ネットワークリクエストを同期処理に変えるわけではありません。

形式

```js
fetch(url, options) // See note 1 below.
```

例の説明：

1. Promiseを返す

awaitの書き方

```js
const 结果 = await Promise
// See note 1 below.
```

例の説明：

1. 後続のコード

- awaitはasync関数内と、トップレベルawaitに対応するESモジュール内で使えます。通常のスクリプトのトップレベルでは直接使えません。
- 結果が返るまで後続のコードは実行されない

非同期の方法

```js
const promise = Promise.resolve('done');
promise
    .then(result => { console.log(result); })
// See note 1 below.
```

例の説明：

1. 後続のコード

- 後続のコードは結果を待たずに実行できる

例：

Expressサーバーにstudents.jsonファイルがある

```json
[
    { "id": 1, "name": "张三", "sex": "男", "age": 18 },
    { "id": 2, "name": "李四", "sex": "女", "age": 17 }
]
```

Fetch APIでこのデータを取得して表示する

awaitの書き方

```html
<script>
    async function findStudents() {
        try {
            // See note 1 below.
            const resp = await fetch('students.json')

            // See note 2 below.
            const array = await resp.json();

            // See note 3 below.
            const tp = document.getElementById("tp");
            const row = tp.content;
            const [c1,c2,c3,c4] = row.querySelectorAll(".col");
            const tbody = document.querySelector('.tbody');
            for(const {id,name,sex,age} of array) {
                c1.textContent = id;
                c2.textContent = name;
                c3.textContent = sex;
                c4.textContent = age;
                // See note 4 below.
                const newRow = document.importNode(row, true);
                // See note 5 below.
                tbody.appendChild(newRow);
            }
        } catch (e) {
            console.log(e);
        }

    }
    findStudents()
</script>
```

例の説明：

1. 応答オブジェクトを取得
2. 応答本文を取得し、JSONとしてJS配列に変換
3. データを表示
4. 要素の複製
5. 親子関係を作る

- fetch('students.json')は内部でリクエストを送信しますが、応答はすぐには返らないため、awaitで応答を待ちます。
- resp.json()も結果をすぐには返せず、Promiseオブジェクトを返すため、awaitと組み合わせて結果を取得します。

非同期の方法

```html
<script>
    fetch('students.json')
        .then( resp => resp.json() )
        .then( array => {
            // See note 1 below.
            const tp = document.getElementById("tp");
            const row = tp.content;
            const [c1,c2,c3,c4] = row.querySelectorAll(".col");
            const tbody = document.querySelector('.tbody');
            for(const {id,name,sex,age} of array) {
                c1.textContent = id;
                c2.textContent = name;
                c3.textContent = sex;
                c4.textContent = age;
                // See note 2 below.
                const newRow = document.importNode(row, true);
                // See note 3 below.
                tbody.appendChild(newRow);
            }
        })
        .catch( e => console.log(e) )


</script>
```

例の説明：

1. データを表示
2. 要素の複製
3. 親子関係を作る

- 最初のthenは応答が返ってから内部のアロー関数を呼び出し、引数respには応答オブジェクトが渡されます。
- 2つ目のthenはJSONの解析完了後にアロー関数を呼び出し、引数には解析結果（この例ではarray配列）が渡されます。
- thenは毎回新しいPromiseを返します。コールバックが通常の値を返すと次のthenに渡され、Promiseを返すとその結果を待ち、例外を投げると後続のcatchへ進みます。

##### クロスオリジンの問題 :id=h-ec726fb36d84

![image-20220814105448882](Resources/image-20220814105448882.png)

- プロトコル、ホスト、ポートのいずれかが異なると、オリジンは異なります。例：
  - <http://localhost:7070/a>と<https://localhost:7070/b>は異なるオリジンです。
- ブラウザーの同一オリジンポリシーは、ページのDOM、ストレージ、スクリプトなどにも関係します。CORSはページによる一部のクロスオリジン応答の読み取りを許可するもので、fetchやXHRが一般的な利用場面です。
  - JavaのHTTPクライアントやPostmanなど、他のクライアントは同一オリジンの検証を行いません。
  - フォーム送信やブラウザーへのURLの直接入力によるリクエストも、同一オリジンの検証を行いません。
- 関連情報は次を参照してください。
  - [オリジン間リソース共有（CORS） - HTTP | MDN（mozilla.org）](https://developer.mozilla.org/zh-CN/docs/Web/HTTP/CORS)

リクエストと応答のヘッダーで解決

![image-20220814144040703](Resources/image-20220814144040703.png)

- クロスオリジンのfetchリクエストは、リクエスト元のリソースがどこから来たかを示すOriginヘッダーを付けます。宛先はこれでクロスオリジンかを識別できます。
  - この例ではstudent.htmlがfetchを送信し、Tomcatにlocalhost:7070由来であることを伝えます。
- 対象リソースはAccess-Control-Allow-Originヘッダーを返し、どのオリジンがこの応答を利用できるかをブラウザーへ伝えます。
  - この例ではTomcatがfetch応答を返し、localhost:7070由来のリソースが利用できるとブラウザーへ伝えます。

プロキシで解決

![image-20220814161532141](Resources/image-20220814161532141.png)

```cmd
npm install http-proxy-middleware --save-dev
```

Expressサーバーの起動コードに追加します。

```js
import {createProxyMiddleware} from 'http-proxy-middleware'

// ...

app.use('/api', createProxyMiddleware({ target: 'http://localhost:8080', changeOrigin: true }));
```

fetchコードを次へ変更します。

```js
const resp = await fetch('http://localhost:7070/api/students')
```

または

```js
const resp = await fetch('/api/students')
```

#### 5) モジュール化 :id=h-2672e7960cb8

const、let、functionを個別にエクスポート

```js
export const a = 10;
export let b = 20;
export function c() {
    console.log('c');
}
```

まとめてエクスポート

```js
const a = 10;
let b = 20;
function c() {
    console.log('c')
}

export {a,b,c}
```

defaultをエクスポート。1つのみ可能

```js
export const a = 10;
export let b = 20;
export function c() {
    console.log('c')
}

export default b;
```

importの構文

```html
<script type="module">
    import { sum } from './math.js';
</script>
```

- importは同一オリジンポリシーに従う必要がある

全体をインポート

```js
import * as module from '/1.js'
console.log(module.a)		// See note 1 below.
console.log(module.b)		// See note 2 below.
module.c()					// See note 3 below.
```

例の説明：

1. 10を出力
2. 20を出力
3. cを出力

個別にインポート

```js
import {a,c} from '/1.js'
console.log(a)				// See note 1 below.
c()							// See note 2 below.
```

例の説明：

1. 10を出力
2. cを出力

デフォルトをインポート

```js
import x from '/1.js'
console.log(x)				// See note 1 below.
```

例の説明：

1. 20を出力

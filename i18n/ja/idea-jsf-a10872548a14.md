# 一、GlassFish で JSF プロジェクトをデプロイする :id=h-90ab6c359e36

JSF プロジェクトに依存関係を追加してデプロイする方法を学び、開発時にコンテナーとパッケージ名を確認します。

**前提知識とバージョン：** 先に JSF の基礎を読んでください。スクリーンショットは IDEA、GlassFish 4/5、JSF 2 を使う過去の環境のものです。メニューやダウンロードページは変わることがあります。Tomcat を使う場合は、対応する Faces 実装を自分で追加する必要があります。新しい連携例は Springboot+JSF+Mybatis.md を参照してください。

**スクリーンショットについて：** 画像には元の学習環境での操作手順を残しています。画像内の古い記述と本文が異なる場合は、改訂後の本文と選択したバージョンの公式ドキュメントに従ってください。

**サンプルの使い方：** 全ファイルと実行手順が明示されたプロジェクトを除き、コードブロックは各節の独立した断片です。省略記号や仮の名前は補ってください。誤りと記された行は問題を説明するためのものです。同じ節の代替コードを組み合わせないでください。

## 1. GlassFish をダウンロードする :id=h-aea58a4214b9

この節のスクリーンショットは、GlassFish 4/5、Java EE、JSF 2 を使う過去の環境のものです。再現する前に、選択した GlassFish の Java と Java EE の要件を確認してください。Jakarta Faces 3/4 の依存関係を混在させないでください。

公式サイト：

```html
GlassFish
https://javaee.github.io/glassfish/
```

Download をクリックします。

![JSF](Resources/JSF-IDEA01.png)

画像に示されたバージョンを選択します。

![](Resources/JSF-IDEA02.png)

ダウンロード後、任意のディレクトリに展開します。

<a id="section-2"></a>

## 2. GlassFish の環境変数を設定する :id=h-c7174f9b4b60

GlassFish の bin ディレクトリをシステム環境変数 Path に追加します。

<a id="section-3"></a>

## 3. JDK の環境変数を変更する :id=h-cf4f14e1c38a

システム環境変数 Path にある既存の jdk1.8 の項目を一番上に移動します。

この文書の旧版 GlassFish の例では JDK 8 を使用します。ほかの GlassFish バージョンでは要件が異なるため、該当バージョンの公式説明に従ってください。PATH の順序だけで判断せず、java -version とサーバーの起動ログで実際に使われる JDK を確認します。

<a id="section-4"></a>

## 4. GlassFish が正常に起動するか確認する :id=h-98d2d9ef07fb

cmd で asadmin start-domain を入力します。次の画像のように表示されれば、設定は成功です。

![](Resources/JSF-IDEA03.png)

asadmin stop-domain を入力すると GlassFish を停止できます。

## 5. IDEA で JSF プロジェクトを作成する :id=h-323f36ac2a56

1. Java Enterprise を選択して Next をクリックします。

   ![](Resources/JSF-IDEA04.png)

2. Web Profile にチェックを入れると、IDEA が JSF を含む必要なフレームワークを自動で選択します。Next をクリックします。

   ![](Resources/JSF-IDEA05.png)

3. モジュール名を入力して Finish をクリックします。

   ![](Resources/JSF-IDEA06.png)

4. IDEA がデフォルトのプロジェクト構成を生成します。

   ![](Resources/JSF-IDEA07.png)

5. デフォルトの POM ファイルの内容

   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <project xmlns="http://maven.apache.org/POM/4.0.0"
            xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
            xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
       <modelVersion>4.0.0</modelVersion>

       <groupId>org.example</groupId>
       <artifactId>jsf-03</artifactId>
       <version>1.0-SNAPSHOT</version>
       <name>jsf-03</name>
       <packaging>war</packaging>

       <properties>
           <maven.compiler.target>1.8</maven.compiler.target>
           <maven.compiler.source>1.8</maven.compiler.source>
           <junit.version>5.6.2</junit.version>
       </properties>

       <dependencies>
           <dependency>
               <groupId>javax</groupId>
               <artifactId>javaee-web-api</artifactId>
               <version>8.0.1</version>
               <scope>provided</scope>
           </dependency>
           <dependency>
               <groupId>org.junit.jupiter</groupId>
               <artifactId>junit-jupiter-api</artifactId>
               <version>${junit.version}</version>
               <scope>test</scope>
           </dependency>
           <dependency>
               <groupId>org.junit.jupiter</groupId>
               <artifactId>junit-jupiter-engine</artifactId>
               <version>${junit.version}</version>
               <scope>test</scope>
           </dependency>
       </dependencies>

       <build>
           <plugins>
               <plugin>
                   <groupId>org.apache.maven.plugins</groupId>
                   <artifactId>maven-war-plugin</artifactId>
                   <version>3.3.0</version>
               </plugin>
           </plugins>
       </build>
   </project>
   ```

6. 生成されたデフォルトのファイルを修正します。修正しないとエラーになります。

   ```xml
   <faces-config xmlns="http://xmlns.jcp.org/xml/ns/javaee"
                 xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
                 xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee
           http://xmlns.jcp.org/xml/ns/javaee/web-facesconfig_2_2.xsd"
                 version="2.2">
   </faces-config>
   ```

7. webapp ディレクトリに index.xhtml ファイルを新規作成します。

   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN"
           "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">
   <html xmlns="http://www.w3.org/1999/xhtml"
         xmlns:h="http://xmlns.jcp.org/jsf/html"
         xmlns:ui="http://xmlns.jcp.org/jsf/facelets"
         xmlns:f="http://xmlns.jcp.org/jsf/core">
   <f:view>
       <h:outputLabel value="Hello, world"/>
   </f:view>
   </html>
   ```

8. 実行環境を設定する

   Run → Edit Configurations をクリックします。

   ![](Resources/JSF-IDEA08.png)

9. 左上の ➕ をクリックし、GlassFish、Local の順に選択します。

   ![](Resources/JSF-IDEA09.png)

10. Configure をクリックし、展開した GlassFish のルートディレクトリを指定します。

    ![](Resources/JSF-IDEA10.png)

11. Deployment、➕、Artifact の順にクリックし、末尾が war_explore の項目を選択します。

    ![](Resources/JSF-IDEA11.png)

12. Apply、Server の順にクリックし、自動生成されたデフォルトの URL を変更します。

    ![](Resources/JSF-IDEA12.png)

13. OK をクリックしてサーバーを起動し、ブラウザーに対応する URL を入力してアクセスします。

    ![](Resources/JSF-IDEA13.png)

## 6. 問題：一部のタグ要素が表示されない :id=h-4160f29c16e8

1. ページのコードは画像のとおりです。

   ```html
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">
   <html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en"
         xmlns:h="http://xmlns.jcp.org/jsf/html"
         xmlns:f="http://xmlns.jcp.org/jsf/core">
   <head>
       MessagesTags
   </head>
   <h:head>
   </h:head>
   <h:body>
       <h:form>
           <h:panelGrid columns="1" width="60%">
               <f:facet name="header">Login</f:facet>
               <f:facet name="footer">
                   <h:outputText value="快到中秋节了"/>
                   <h:commandButton action="Layoutpage" value="Submit"/>
               </f:facet>
               <h:panelGroup>
                   <h:outputText value="Enter ID:"/><h:inputText id="it1" required="true" requiredMessage="ynb"/>
                   <h:message for="it1"/>
               </h:panelGroup>
               <h:panelGroup>
                   <h:inputSecret required="true">
                       <h:outputLabel value="Enter Password"/>
                   </h:inputSecret>
               </h:panelGroup>
           </h:panelGrid>
           <h:messages/>
       </h:form>
   </h:body>
   </html>
   ```

2. 実行結果の画面

   ![](Resources/JSF-IDEA14.png)

3. エラーの内容：

   ```
   Error in event handler: Error: Failed to execute 'appendChild' on 'Node': This node type does not support this method.
       at Updater.check (chrome-extension://fhopckooaleifhophcpcakhfkajmnffo/js/gmWrapper.js:4:3204)
       at init (chrome-extension://fhopckooaleifhophcpcakhfkajmnffo/js/jquery-1.7.2.js:1:3311)
       at onReadyGM (chrome-extension://fhopckooaleifhophcpcakhfkajmnffo/js/jquery-1.7.2.js:1:76)
       at Object.onInitializedGM (chrome-extension://fhopckooaleifhophcpcakhfkajmnffo/js/gmWrapper.js:4:636)
       at Object.callbackResponse (chrome-extension://fhopckooaleifhophcpcakhfkajmnffo/js/gmWrapper.js:4:331)
       at chrome-extension://fhopckooaleifhophcpcakhfkajmnffo/js/gmWrapper.js:4:3378
   ```

4. 原因：web.xml の設定が誤っている

```xml
<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xmlns="http://xmlns.jcp.org/xml/ns/javaee" xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee http://xmlns.jcp.org/xml/ns/javaee/web-app_4_0.xsd" version="4.0">
    <display-name>JSF_SE_CH2_html01_0915</display-name>
    <servlet>
        <servlet-name>Faces Servlet</servlet-name>
        <servlet-class>javax.faces.webapp.FacesServlet</servlet-class>
        <load-on-startup>1</load-on-startup>
    </servlet>
    <servlet-mapping>
        <servlet-name>Faces Servlet</servlet-name>
        <url-pattern>/faces/*</url-pattern>
    </servlet-mapping>
    <context-param>
        <description>State saving method: 'client' or 'server' (=default). See JSF Specification 2.5.2</description>
        <param-name>javax.faces.STATE_SAVING_METHOD</param-name>
        <param-value>client</param-value>
    </context-param>
    <context-param>
        <param-name>javax.servlet.jsp.jstl.fmt.localizationContext</param-name>
        <param-value>resources.application</param-value>
    </context-param>
    <listener>
        <listener-class>com.sun.faces.config.ConfigureListener</listener-class>
    </listener>
    <welcome-file-list>
        <welcome-file>faces/index.xhtml</welcome-file>
    </welcome-file-list>
</web-app>
```

5. この画像の環境では、コンテナーによる FacesServlet の自動登録により、重複する手動設定を減らせます。これは汎用的な修正方法ではありません。まずリクエストの URL が FacesServlet に対応しているか、依存関係が一致しているか、サーバーログに初期化エラーがないかを確認してください。有効な Servlet や Listener の設定を安易に削除しないでください。以下は、その古い環境で自動登録を使った際の記述子の記録です。

   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <web-app xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xmlns="http://xmlns.jcp.org/xml/ns/javaee" xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee http://xmlns.jcp.org/xml/ns/javaee/web-app_4_0.xsd" version="4.0">
       <display-name>JSF_SE_CH2_html01_0915</display-name>

       <welcome-file-list>
           <welcome-file>faces/index.xhtml</welcome-file>
       </welcome-file-list>
   </web-app>
   ```

6. 実行画面です。これで設定は完了です。

   ![](Resources/JSF-IDEA15.png)

## 7. web.xml にデフォルトの開始ページを設定する :id=h-776421dfc2e0

```xml
<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns="http://xmlns.jcp.org/xml/ns/javaee"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee http://xmlns.jcp.org/xml/ns/javaee/web-app_4_0.xsd"
         version="4.0">
    <welcome-file-list>
        <welcome-file>index.xhtml</welcome-file>
    </welcome-file-list>
    <servlet>
        <servlet-name>Faces Servlet</servlet-name>
        <servlet-class>javax.faces.webapp.FacesServlet</servlet-class>
        <load-on-startup>1</load-on-startup>
    </servlet>
    <servlet-mapping>
        <servlet-name>Faces Servlet</servlet-name>
        <url-pattern>*.xhtml</url-pattern>
    </servlet-mapping>
</web-app>
```

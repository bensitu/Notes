# Modern Java development: language, collections, and concurrency :id=h-1227d6c277f2

Learning objectives: understand common modern Java idioms and their limits before reading Spring projects. Requires basic Java classes, methods, and exceptions.

**Scope:** The main learning path recommends JDK 25 LTS. The running backend compiles with release 17 and runs on Java 17 or 25. The record example below needs Java 17+; virtual threads need Java 21+. No preview features are used.

## Minimal runnable example :id=h-7dd27c75225c

Save as ModernJavaDemo.java:

```java
import java.util.List;
import java.util.Objects;

public class ModernJavaDemo {
    record Task(long id, String title) {
        Task {
            Objects.requireNonNull(title, "title");
            title = title.strip();
            if (title.isEmpty()) throw new IllegalArgumentException("title is blank");
        }
    }

    public static void main(String[] args) {
        var tasks = List.of(new Task(1, " Learn Java "), new Task(2, "Write tests"));
        var titles = tasks.stream().map(Task::title).toList();
        System.out.println(titles);
    }
}
```

```powershell
javac -encoding UTF-8 --release 17 ModernJavaDemo.java
java ModernJavaDemo
```

Expect \[Learn Java, Write tests]. Lists returned by List.of and Stream.toList cannot be used to add or remove elements; neither deeply freezes all objects inside those elements.

## record, Optional, and time :id=h-00965d60fe9f

record automatically supplies accessors, equals, hashCode, and toString. Its accessor is title(), not getTitle(). Non-reassignable field references do not automatically make a referenced List immutable. Consider element mutability when copying collections too.

Optional suits possibly absent return values and is not usually for entity fields or request JSON. Do not call get() first and use exceptions instead of normal branching.

Use LocalDate for business dates, Instant for absolute instants, and ZoneId / ZonedDateTime when regional time-zone rules matter. Define time zones for the database, API, and display layer; LocalDateTime itself has no time zone.

Use BigDecimal for money with explicit decimal scale and rounding rules. Do not construct exact monetary values from double or confuse equals with numerical comparison compareTo.

## Virtual threads: cheaper waiting :id=h-eb64fb76e7f3

The following method-body fragment must go inside a class method and use JDK 21+:

```java
try (var executor = java.util.concurrent.Executors.newVirtualThreadPerTaskExecutor()) {
    var future = executor.submit(() -> "completed");
    System.out.println(future.get(2, java.util.concurrent.TimeUnit.SECONDS));
}
```

Virtual threads suit large numbers of blocking tasks; they do not automatically speed up CPU-intensive computation. Cheap threads do not mean unlimited database connections, external APIs, or memory.

A get timeout does not automatically cancel the task. Call cancel according to business needs and make tasks respond correctly to interruption. Do not swallow InterruptedException; preserve the interrupt status or propagate according to the method contract if execution cannot continue.

## Verification and common errors :id=h-a8b0965689e1

Check compile and runtime versions separately: java -version, javac -version, mvn -version. A working IDE does not mean CI uses the same JDK.

Do not assume wrapping database calls in parallel Streams improves throughput. Measure connection pools, external rate limits, and latency first. Shared HashMap, counters, and mutable fields in singleton Beans require thread-safety consideration.

## Development quick reference :id=h-8efae9d8a41f

- Validate parameters at entry points; core business logic must still maintain its own invariants.
- Close owned resources with try-with-resources; do not arbitrarily close or commit borrowed connections.
- Choose collections by access patterns; method names do not determine performance.
- Prefer constructor injection and reduce uncontrolled global mutable state.
- When upgrading JDK, verify build plugins, proxy libraries, monitoring tools, and container base images together.

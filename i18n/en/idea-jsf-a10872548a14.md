# I. Deploying a JSF project with GlassFish :id=h-90ab6c359e36

Learn how to add dependencies to and deploy a JSF project, checking the container and package names during development.

**Prerequisites and versions:** Read JSF Basics first. Screenshots come from a historical environment using IDEA, GlassFish 4/5, and JSF 2; menus and download pages may change. With Tomcat, add a compatible Faces implementation yourself. For a newer integration example, see Springboot+JSF+Mybatis.md.

**About screenshots:** Images retain the steps from the original teaching environment. If older code in a screenshot differs from the text, follow the revised text and the official documentation for your selected version.

**Using the examples:** Unless a project explicitly lists all files and run instructions, code blocks are independent snippets for each section. Fill in ellipses and placeholder names; lines marked as incorrect illustrate problems. Do not combine alternative implementations from the same section.

## 5. Create a JSF project in IDEA :id=h-323f36ac2a56

1. Select Java Enterprise and click Next

   ![](Resources/JSF-IDEA04.png)

2. Select Web Profile. IDEA automatically selects the other required frameworks, including JSF. Click Next.

   ![](Resources/JSF-IDEA05.png)

3. Enter the module name and click Finish

   ![](Resources/JSF-IDEA06.png)

4. IDEA generates the default project structure

   ![](Resources/JSF-IDEA07.png)

5. Default POM file contents

   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <project xmlns="http://maven.apache.org/POM/4.0.0"
            xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
            xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
       <modelVersion>4.0.0</modelVersion>

       <groupId>org.example</groupId>
       <artifactId>jsf-03</artifactId>
       <version>1.0-SNAPSHOT</version>
       <name>jsf-03</name>
       <packaging>war</packaging>

       <properties>
           <maven.compiler.target>1.8</maven.compiler.target>
           <maven.compiler.source>1.8</maven.compiler.source>
           <junit.version>5.6.2</junit.version>
       </properties>

       <dependencies>
           <dependency>
               <groupId>javax</groupId>
               <artifactId>javaee-web-api</artifactId>
               <version>8.0.1</version>
               <scope>provided</scope>
           </dependency>
           <dependency>
               <groupId>org.junit.jupiter</groupId>
               <artifactId>junit-jupiter-api</artifactId>
               <version>${junit.version}</version>
               <scope>test</scope>
           </dependency>
           <dependency>
               <groupId>org.junit.jupiter</groupId>
               <artifactId>junit-jupiter-engine</artifactId>
               <version>${junit.version}</version>
               <scope>test</scope>
           </dependency>
       </dependencies>

       <build>
           <plugins>
               <plugin>
                   <groupId>org.apache.maven.plugins</groupId>
                   <artifactId>maven-war-plugin</artifactId>
                   <version>3.3.0</version>
               </plugin>
           </plugins>
       </build>
   </project>
   ```

6. Modify the generated default file; otherwise an error occurs

   ```xml
   <faces-config xmlns="http://xmlns.jcp.org/xml/ns/javaee"
                 xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
                 xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee
           http://xmlns.jcp.org/xml/ns/javaee/web-facesconfig_2_2.xsd"
                 version="2.2">
   </faces-config>
   ```

7. Create an index.xhtml file in the webapp directory

   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN"
           "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">
   <html xmlns="http://www.w3.org/1999/xhtml"
         xmlns:h="http://xmlns.jcp.org/jsf/html"
         xmlns:ui="http://xmlns.jcp.org/jsf/facelets"
         xmlns:f="http://xmlns.jcp.org/jsf/core">
   <f:view>
       <h:outputLabel value="Hello, world"/>
   </f:view>
   </html>
   ```

8. Configure the run environment

   Click Run → Edit Configurations

   ![](Resources/JSF-IDEA08.png)

9. Click ➕ at the top left, then select GlassFish and Local

   ![](Resources/JSF-IDEA09.png)

10. Click Configure and locate the root directory of your extracted GlassFish installation

    ![](Resources/JSF-IDEA10.png)

11. Click Deployment, then ➕, then Artifact, and select the item ending in war_explore

    ![](Resources/JSF-IDEA11.png)

12. Click Apply, then Server, and change the generated default URL

    ![](Resources/JSF-IDEA12.png)

13. Click OK, start the server, and enter the corresponding URL in a browser

    ![](Resources/JSF-IDEA13.png)

First check whether the request URL reaches FacesServlet, dependencies are consistent, and server logs contain initialization errors. Do not simply delete valid Servlet or Listener configuration. ## 7. Configure the default start page in web.xml :id=h-776421dfc2e0

```xml
<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns="http://xmlns.jcp.org/xml/ns/javaee"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee http://xmlns.jcp.org/xml/ns/javaee/web-app_4_0.xsd"
         version="4.0">
    <welcome-file-list>
        <welcome-file>index.xhtml</welcome-file>
    </welcome-file-list>
    <servlet>
        <servlet-name>Faces Servlet</servlet-name>
        <servlet-class>javax.faces.webapp.FacesServlet</servlet-class>
        <load-on-startup>1</load-on-startup>
    </servlet>
    <servlet-mapping>
        <servlet-name>Faces Servlet</servlet-name>
        <url-pattern>*.xhtml</url-pattern>
    </servlet-mapping>
</web-app>
```

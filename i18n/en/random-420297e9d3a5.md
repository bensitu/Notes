## What is Random? :id=h-641007e74d21

java.util.Random generates pseudorandom numbers, calculated by an algorithm from a seed. The same seed and sequence of method calls produce the same sequence of values, which is useful for repeatable tests.

```java
import java.util.Random;

public class RandomExample {
    public static void main(String[] args) {
        Random random = new Random(42L);
        System.out.println(random.nextInt(10));
        System.out.println(random.nextDouble());
        System.out.println(random.nextBoolean());
    }
}
```

Save as RandomExample.java, then run javac RandomExample.java and java RandomExample. Restarting the program produces the same sequence each time.

## Method quick reference :id=h-bd73409bb033

| Method                     | Result                                                                   |
| -------------------------- | ------------------------------------------------------------------------ |
| new Random()               | Creates a generator without an explicitly supplied seed                  |
| new Random(seed)           | Supplies a seed for repeatable experiments                               |
| nextInt()                  | An integer in the int range; negative values are possible                |
| nextInt(bound)             | \[0, bound): includes 0 and excludes bound; bound must be positive       |
| nextLong()                 | An integer in the long range                                             |
| nextFloat() / nextDouble() | \[0.0, 1.0): excludes 1.0                                                |
| nextBoolean()              | true or false                                                            |
| nextGaussian()             | Approximately normally distributed, with mean 0 and standard deviation 1 |

## Choosing an integer range :id=h-8c0427c60ff8

Generate \[50, 99], including both endpoints:

```java
Random random = new Random();
int start = 50;
int end = 99;
int number = random.nextInt(end - start + 1) + start;
```

Generate \[0, 50) and add 50 to obtain 50 through 99. The +1 includes the upper bound. Put this fragment inside a method and import java.util.Random.

The formula requires start <= end and a positive int that can hold end - start + 1. Do not apply it directly to the entire int range, because the calculation can overflow.

## Choosing an API :id=h-362f444747e1

Use java.security.SecureRandom when unpredictability is required for passwords, verification codes, or session tokens. Do not use a fixed seed or treat Random output as a secure token.

For ordinary random numbers under high concurrency, consider ThreadLocalRandom. Check the JDK version when selecting an API; newer range overloads are not directly available on older JDK versions.

References: [Random API](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/Random.html) and [SecureRandom API](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/security/SecureRandom.html).
